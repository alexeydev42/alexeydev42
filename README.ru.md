## Основные проекты

### [PhraseCue](https://github.com/alexeydev42/phrase-cue)

Mobile-first приложение на React и TypeScript для сохранения и изучения английских фраз из субтитров к сериалам.

Есть импорт SRT, поиск реплик по таймкоду, редактирование и перевод фраз, режим обучения, хранение данных в IndexedDB и JSON-бэкапы. Перевод работает через serverless API с резервным endpoint и rate limiting.

В проекте настроены автоматические тесты, CI и опубликован релиз v1.2.0.

[Демо](https://alexeydev42.com/phrase-cue/) · [v1.2.0](https://github.com/alexeydev42/phrase-cue/releases/tag/v1.2.0)

### [SkillSwap](https://github.com/alexeydev42/SkillSwap_55_3)

Командное приложение на React и TypeScript для обмена навыками. Работал в роли помощника тимлида и фронтенд-разработчика, в основном занимался логикой приложения, Redux-состоянием, маршрутизацией и пользовательскими сценариями.

После завершения командного этапа продолжил развивать форк самостоятельно: добавил адаптивные версии интерфейса, светлую и тёмную темы, редактирование навыка, деплой на GitHub Pages и регрессионные тесты.

[Демо](https://alexeydev42.com/SkillSwap_55_3/)

### [Portfolio Website](https://github.com/alexeydev42/alexeydev42.github.io)

Мой личный сайт-портфолио на React и TypeScript. В нём есть адаптивная вёрстка, английская и русская версии, просмотр проектов и сертификатов, отдельные состояния для клавиатуры и touch-устройств, автоматические UI-тесты, аналитика и доработки accessibility.

[Демо](https://alexeydev42.com/) · [v1.0.0](https://github.com/alexeydev42/alexeydev42.github.io/releases/tag/v1.0.0)

### [Stellar Burgers](https://github.com/alexeydev42/stellar-burgers)

React/TypeScript-приложение с авторизацией, защищёнными маршрутами, Redux Toolkit, интеграцией с API и автоматическими тестами.
